**BLOCKMANIA**: a toy-block roguelike of tricks, Jokers and one very full board. In-development build: everything in the README is playable, balance numbers are provisional.

## Download and play

| Your computer | File | How to start |
|---|---|---|
| **Windows** 10/11 (64-bit) | `BLOCKMANIA-Windows.zip` | Unzip, double-click `BLOCKMANIA.exe`. If SmartScreen appears: **More info → Run anyway**. |
| **Mac** (Apple Silicon and Intel, macOS 11+) | `BLOCKMANIA-macOS.zip` | Unzip, drag `BLOCKMANIA.app` to Applications, then **right-click → Open** the first time. |
| **Linux** (64-bit) | `BLOCKMANIA-Linux.zip` | Unzip, run `BLOCKMANIA.x86_64`. |

The builds are not code-signed or notarized yet, which is why Windows and macOS ask once. No install, no account, no internet needed. Saves stay in your user folder.

Controls: drag pieces with the mouse (or 1–3, arrows, Enter). `H` hold, `R` refresh, `Esc` pause. POPS the helper shows you the rest on your first run.
