# Third-party components and provenance

| Component | Path | Version | License | Use | Ships in release? |
|---|---|---|---|---|---|
| Godot Engine | (external) | 4.7.2 stable | MIT | Engine | Yes (runtime) |
| Godot AI editor plugin | `addons/godot_ai/` | 4.2.1 | MIT (`addons/godot_ai/LICENSE`) | Development tooling: MCP bridge between AI assistants and the editor | The addon files ship inside the current downloadable builds because its `_mcp_game_helper` autoload is registered by the plugin; in exported release builds it stays idle (no debugger channel). Remove or gate it before a store release (TASKS.md M2). |
| Fusion Pixel Font (10 px proportional), subset | `assets/fonts/cjk_ja.ttf`, `cjk_zh_cn.ttf`, `cjk_zh_tw.ttf` | 2026.09.01 release | SIL Open Font License 1.1 (`assets/fonts/licenses/fusion-pixel-OFL.txt`; includes Ark Pixel, Boutique Bitmap 9x9 and Galmuri glyphs, licenses beside it) | Japanese and Chinese fallback glyphs for the Blockhead fonts. Subset to the characters the translations use and renamed "Blockmania CJK" (the OFL reserves the original name) by `tools/art/gen_cjk_fonts.py`; source: github.com/TakWolf/fusion-pixel-font releases (zip not committed) | Yes |

No other external code, fonts, images, or audio are included; the Latin accents in Blockhead are original like the rest of the font. The UI kit (`assets/ui/`) and the Blockhead fonts (`assets/fonts/`) are original works generated by `tools/art/gen_ui.py` and `tools/art/gen_font.py`. The shaders in `game/presentation/shaders/` and the particle system are original project code. No VFX library was imported. Image-generator files under `assets/source/generated/` (owner's local folder, not in the repository) are not used by the game.
