# Third-party components and provenance

| Component | Path | Version | License | Use | Ships in release? |
|---|---|---|---|---|---|
| Godot Engine | (external) | 4.7.2 stable | MIT | Engine | Yes (runtime) |
| Godot AI editor plugin | `addons/godot_ai/` | 4.2.1 | MIT (`addons/godot_ai/LICENSE`) | Development tooling: MCP bridge between AI assistants and the editor | No: every export preset excludes `addons/godot_ai/*`, and its export plugin strips the `_mcp_game_helper` autoload (checked on the Steam build, 2026-09-25). |
| GodotSteam GDExtension | `addons/godotsteam/` (git-ignored; `tools/release/install_godotsteam.sh`) | 4.22.1 (Steamworks SDK 1.65) | MIT (`addons/godotsteam/license.md`) | Steam achievements (`BMSteam`) | Yes: the GodotSteam library plus Valve's Steamworks redistributable (`steam_api64.dll`, `libsteam_api.so`, `libsteam_api.dylib`), shipped under the Steamworks SDK Access Agreement. |

No other external code, fonts, images, or audio are included. The UI kit (`assets/ui/`) and the Blockhead fonts (`assets/fonts/`) are original works generated by `tools/art/gen_ui.py` and `tools/art/gen_font.py`. The shaders in `game/presentation/shaders/` and the particle system are original project code. No VFX library was imported. Image-generator files under `assets/source/generated/` (owner's local folder, not in the repository) are not used by the game.
